## 🌟 Overview

Welcome to **The Carbon Chain Chandelier & Alkane Lamp System** — where organic chemistry meets modern Scandinavian sculptural lighting. 

Inspired by iconic designer fixtures and molecular geometry, this project brings the fundamental building blocks of organic matter to life. Instead of arbitrary decorative shapes, every node, angle, and connection in this lamp is derived from **real covalent bonding geometry** ($\text{sp}^3$ hybridization with the exact **$109.47^\circ$** tetrahedral bond angle).

This first release features the **Propane ($C_3H_8$) Standing & Table Lamp**: a stunning 3-carbon backbone lamp with an integrated tilted base plate, hidden internal wiring channels, and modular socket connections.

It serves as the flagship model and the foundation for a **complete modular kit** — allowing you to expand from a single node to full organic chandeliers (**The Carbon Chain Chandelier** series), desk lamps, and sculptural floor installations.

## 🧪 The Science Behind the Design

Alkanes are saturated hydrocarbons consisting entirely of single-bonded carbon and hydrogen atoms.

```
       H   H   H
       |   |   |
   H - C - C - C - H       Propane (C₃H₈)
       |   |   |
       H   H   H
```

### 1. Tetrahedral Carbon & $\text{sp}^3$ Hybridization
In an alkane, each carbon atom undergoes $\text{sp}^3$ hybridization, forming four equivalent covalent bonds directed toward the vertices of a regular tetrahedron. The mathematical bond angle is:
$$\theta = \arccos\left(-\frac{1}{3}\right) \approx 109.47122^\circ$$
Every node in this lamp model strictly adheres to this $109.47^\circ$ angle, giving it a natural, mathematically harmonious silhouette.

### 2. Staggered (*Anti* / *Gauche*) Conformation
Due to free rotation around the carbon-carbon ($\text{C}-\text{C}$) single $\sigma$-bonds, alkane chains naturally settle into a **staggered conformation**. This minimizes steric clash and torsional strain (Pitzer strain), resulting in the characteristic organic **zigzag backbone**. The Propane Lamp captures this exact 3D zigzag configuration in a self-balancing, visually captivating standing posture.

## ✨ Features & Highlights

- 🧩 **True Modular Architecture:** Interchangeable tetrahedral carbon nodes, connector sleeves, weighted base plates, and socket adapters.
- 🧵 **Internal Cable Routing:** Generous continuous hollow internal bores ($\varnothing 43\,\text{mm}$) and an integrated base plate cable canal ($\varnothing 7\,\text{mm}$ with smooth chamfers) allow you to run standard electrical cables cleanly inside the lamp with zero exposed wires.
- 📐 **Self-Stabilizing Geometry:** The 160 mm base plate is tilted and counterbalanced to firmly support the 3-node propane structure with standard E27/E14 light fixtures and globes.
- 🖨️ **Optimized for FDM 3D Printing:** Designed to print with clean layer lines, robust wall thicknesses, and minimal/no unnecessary supports.
- ⚡ **Standard Hardware Compatibility:** Designed for readily available E27 / E14 lamp sockets, Bambu LED Lamp Kits, or custom pendant cords.

## 🛒 Bill of Materials (BOM) & Required Hardware

To complete the electrical build, you will need:

1. **Light Bulb Socket:**
   - 1x Standard **E27** (or **E14**) threaded socket with mounting collar / screw ring.
   - *Alternative:* Compatible with Bambu Lab LED Lamp Kit 001.
2. **Power Cord & Switch:**
   - 1x 2-conductor or 3-conductor lamp cord with inline switch and wall plug (cord diameter up to $6.5\,\text{mm}$).
3. **Light Bulb:**
   - 1x **LED Globe Bulb** (G80, G95, or G125 vintage filament LED recommended).
   - ⚠️ **IMPORTANT:** Use **LED bulbs only** ($\le 9\,\text{W}$ power consumption). Never use incandescent or halogen bulbs due to heat accumulation inside 3D printed plastics.
4. **Adhesive / Assembly (Optional):**
   - A few drops of Cyanoacrylate (Super Glue) or 2-part epoxy for locking connector sleeves if non-threaded slip fits are used.

## 🖨️ Recommended Print Settings

Optimized for **Bambu Lab X1-Carbon / P1S / A1** or any standard FDM printer with $\ge 180 \times 180 \times 180\,\text{mm}$ build volume.

| Parameter | Recommended Setting | Rationale |
| :--- | :--- | :--- |
| **Filament Type** | **PLA Matte / PLA-CF / PETG** | PLA Matte gives a premium designer ceramic look; PETG offers higher thermal resistance. |
| **Layer Height** | **0.16 mm – 0.20 mm** | 0.16 mm provides ultra-smooth curves on tetrahedral fillets. |
| **Wall Loops (Perimeters)** | **4 – 5 Walls** | Crucial for structural rigidity, thread strength, and clean overhangs. |
| **Infill** | **15% – 25% Gyroid** | High torsional resistance and zero resonance. |
| **Base Plate Infill** | **40% – 60% Infill** | Adds weight to the lower base plate for maximum stability. |
| **Supports** | **Tree Supports (Auto / Organic)** | Only needed for downward steep overhangs on certain arm angles. Base and sleeves print support-free. |
| **Brim** | **Outer brim only (5 mm)** | Recommended for tall narrow node orientations. |

## 🔧 Step-by-Step Assembly Guide

```
[Base Plate] ──► [Node 1 + Foot] ──► [Connector Pipe] ──► [Node 2] ──► [Connector Pipe] ──► [Node 3] ──► [E27 Socket + Bulb]
      │                                                                                                    ▲
      └──────────────────────── Internal Cable Routing (7 mm Bore) ────────────────────────────────────────┘
```

1. **Cable Pre-Routing:**
   - Thread your lamp cable from the bottom/rear cable exit hole through the channel in the **Base Plate**.
   - Feed the cable upwards through the hollow leg of **Node 1**.
2. **Backbone Assembly:**
   - Insert the **Connector Sleeve** between Node 1 and Node 2. Guide the cable through the center.
   - Attach Node 3 using the second connector sleeve. Ensure all nodes align with their tetrahedral indexing keys.
3. **Socket Wiring:**
   - Strip the wire ends ($5\,\text{mm}$) and connect them firmly to your E27/E14 socket terminals.
   - Seat the socket into the top terminal of **Node 3** and secure it using the socket collar or threaded insert.
4. **Base Plate Securing:**
   - If using the split-plate model, insert the foot into the base plate socket and secure with glue or the locknut.
   - Apply self-adhesive rubber/felt pads underneath the base plate to protect your desk/floor.
5. **Install Bulb & Test:**
   - Screw in your favorite LED globe bulb.
   - Plug into the wall outlet and switch on!

## ⚡ Safety & Electrical Disclaimer

> [!CAUTION]
> **Electrical Safety Notice:**
> - Working with mains voltage ($110\,\text{V} / 230\,\text{V}$) requires proper care. If you are not familiar with electrical wiring, purchase a pre-assembled lamp cord set (cord + inline switch + pre-wired socket) or consult a certified electrician.
> - **Only use LED bulbs (maximum 9W).** Traditional incandescent bulbs produce excessive heat that can deform PLA/PETG prints.
> - Ensure no bare copper wire touches printed parts and that proper strain relief is applied.
